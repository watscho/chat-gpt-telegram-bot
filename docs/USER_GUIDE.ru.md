# Telegram AI Bot Pro: руководство

Бот работает в личных сообщениях только для пользователей из разрешённого списка. Возможности используют OpenAI API и оплачиваются по условиям провайдера. Название Pro относится к возможностям этого проекта.

## Общение и поиск

Пишите обычные сообщения или отправляйте голосовые. Для голосового бот сначала показывает расшифровку, затем ответ. Язык ответа следует языку запроса.

Для поиска используйте `/search запрос`, например:

```text
/search Что изменилось в последнем релизе Node.js?
```

Бот может сам выбрать поиск, если вопрос требует свежих данных. В ответе появляются ссылки `[1]`, `[2]` и отдельный список источников с кликабельными адресами. Проверяйте важные выводы по самим источникам. Если источников нет, бот не создаёт их список искусственно.

## Фото

Пришлите фотографию с подписью «что здесь изображено?» или «прочитай текст». Без подписи бот начнёт с описания. После этого можно задавать уточняющие вопросы.

- `/image описание` — создать изображение.
- `/edit что изменить` — изменить изображение из контекста.
- Ответ на конкретное фото или созданный PNG с `/edit …` — выбрать именно этот исходник.

Команды также работают в подписи к фото. Обычные просьбы «создай картинку» и «замени фон» тоже могут вызывать генерацию. Результаты отправляются оригинальным PNG-файлом. По умолчанию выбрано высокое качество. Редактирование является генеративным: точное сохранение каждого пикселя не гарантируется.

Поддерживаются JPEG, PNG и статический WebP. Несколько референсов можно отправить альбомом. Бот собирает обновления 750 мс; поздние элементы могут получить ответ «Busy». Для гарантированного последовательного добавления дождитесь ответа на каждый файл.

## Документы

Поддерживаются PDF, DOCX, XLSX, PPTX, TXT, MD, CSV и JSON. Текстовые файлы должны быть в UTF-8.

Отправьте документ с подписью:

```text
Сделай краткое резюме. Укажи страницы с ключевыми условиями.
```

Без подписи бот подготовит начальное резюме. Затем можно спрашивать «что сказано в разделе 4?» или «переведи этот фрагмент». Чтобы выбрать старый документ, ответьте на сообщение с ним. Контекст ограничен сроком хранения и объёмом: при необходимости прикрепите файл снова. Если важны изображения и оформление офисного документа, предварительно сохраните его в PDF.

## Отдельные диалоги

```text
/new Работа
/chats
/switch 1
/rename Личное
/delete 2
```

У каждого диалога своя история текста и вложений. `/chats` показывает номера и текущий выбор. Нельзя переключиться на диалог другого пользователя. Последний диалог удалить нельзя: очистите его через `/reset`.

`/new` создаёт новый диалог. `/reset` очищает только текущий. `/start` и `/help` показывают справку и ничего не очищают.

При обычном запуске данные сохраняются в SQLite и переживают перезапуск. История по умолчанию действует один час бездействия, содержит до 20 полных обменов и ограничена объёмом. Названия диалогов сохраняются отдельно от истории. При заполнении лимитов старые данные удаляются. Это не бессрочный архив.

## Управляемая память

```text
/remember Отвечай кратко по-русски.
/memory
/forget 1
/forget all
```

Также понимаются явные просьбы «запомни: …» и «забудь …». После «забудь» можно указать номер или точный текст заметки; «забудь всё» удалит все заметки.

Заметки доступны во всех ваших диалогах. Бот не сохраняет факты автоматически из обычной беседы. Память других пользователей недоступна. `/reset` не удаляет заметки. `/forget` удаляет сохранённую заметку, но не меняет старые ответы, в которых она могла упоминаться: при необходимости очистите соответствующие диалоги.

## Голосовые ответы

```text
/voice on
/voice auto
/voice off
/speak Произнеси этот текст
/speak
```

- `on` — озвучивать текстовые ответы.
- `auto` — озвучивать ответы только на входящие голосовые.
- `off` — обычные текстовые ответы; это начальная настройка.
- `/speak` без текста — озвучить последний сохранённый ответ текущего диалога.

Каждое аудио помечено как созданное ИИ. Голосовые ответы требуют доступа к Realtime-модели и установленного FFmpeg с libopus. Если озвучивание не удалось, текст остаётся доступен. Слишком длинные ответы не обрезаются молча: выберите короткий отрывок для `/speak`.

## Данные и ограничения

По умолчанию файл ограничен 10 МБ. История и вложения имеют дополнительные общие лимиты. Пока запрос выполняется, другие запросы и команды от того же пользователя получают «Busy»; дождитесь завершения.

Текст, голос, файлы, сохранённые заметки и нужная история передаются OpenAI. При поиске запросы могут передаваться поисковым провайдерам. История и вложения также сохраняются локально; база данных не шифруется самим приложением. Оператор должен защищать её и резервные копии. Ошибки провайдера отображаются без приватных технических подробностей.

Подробные настройки и правила хранения: [configuration.md](configuration.md) и [operations.md](operations.md).
